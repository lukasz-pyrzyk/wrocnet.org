Miejsce: Politechnika Wrocławska, Aula główna budynku D20, ul. Janiszewskiego 8, Wrocław

Interesują Cię najnowsze technologie? To powinno Cię zainteresować!

Wrocławska społeczność pasjonatów technologii Microsoft serdecznie zaprasza na wydarzenie: **Heroes {Community} Launch**.

Heroes {Community} Launch będzie skupione wokół najnowszych produktów firmy Microsoft: **Windows Server 2008**, **Visual Studio 2008** oraz **SQL Server 2008**. Organizatorzy zaproszą najlepszych prelegentów z firm IT z całego świata. Dodatkowo podczas wydarzenia będzie szansa na nawiązanie nowych znajomości w strefie społeczności, sprawdzenia swojej wiedzy podczas licznych konkursów, jak również zabawy i zrelaksowania się podczas turnieju XBOX. Na zakończenie zapraszamy na przyjęcie po-konferencyjne. Spotkanie to będzie szansą na miłe spędzenie czasu w doborowym towarzystwie oraz na podsumowanie konferencji.

### Kluczowe informacje

**Tematyka:** Visual Studio 2008, SQL Server 2008, Windows 2008, Silverlight, WPF
**Liczba uczestników:** 600+

#### Cele:
* Zaprezentowanie produktów Microsoft Windows Server 2008™, Visual Studio 2008™ oraz SQL Server 2008™.
* Nawiązanie współpracy pomiędzy partnerami, uczestnikami spotkania.
* Integracja członków wrocławskich społeczności pasjonatów technologii Microsoft.
* Promocja wizerunku firm wspierających wydarzenie.
* Wymiana doświadczeń pomiędzy uczestnikami spotkania.

#### Atrakcje towarzyszące:
* Konkursy poświęcone prezentowanym produktom.
* Turniej XBOX z nagrodami.
* Przyjęcie po-konferencyjne w jednym z wrocławskich klubów.

### Organizatorzy

#### Wrocławska Grupa .NET
Wrocławska Grupa .NET (Wroc.NET) jest bardzo młodą, ale niezwykle dynamicznie rozwijająca się społecznością, którą założył Łukasz Olbromski. Rozpoczęła działalność w listopadzie zeszłego roku, a już udało jej się odbyć kilka spotkań, przeprowadzić warsztaty integracyjne, gościć Tomasza Kopacza czy współorganizować Install Fest we Wrocławiu. Liczne inicjatywy są wspierane przez coraz liczniejszą grupę sponsorów. Poza tym Wroc.NET należy do międzynarodowego stowarzyszenia INETA oraz nawiązuje bliską współpracę z innymi społecznościami Microsoft: akademickim grupami .NET, Polish SQL Server User Group, a także korzysta z wiedzy i doświadczenia starszych organizacji jak: Krakowska Grupa .NET, Poznańska Grupa .NET, Warszawska Grupa .NET oraz Trójmiejska Grupa .NET.

#### Grupa .NET Politechniki Wrocławskiej na wydziale Elektroniki
Grupa .NET EKA działa jako sekcja Koła Naukowego Studentów "Horyzont" na Wydziale Elektroniki Politechniki Wrocławskiej. Głównym celem działalności jest poznawanie oraz rozpowszechnianie wśród studentów technologii Microsoft.NET. Wymieniając się doświadczeniami wspólnie pracujemy nad ciekawymi projektami informatycznymi, uczymy się pracy w grupie oraz umiejętności kierowania zespołem.

#### Grupa .NET Uniwersytetu Wrocławskiego
Grupa.NET UWr. jest akademicką społecznością pasjonatów technologii .NET przy Instytucie Informatyki Uniwersytetu Wrocławskiego. Założona w 2003 roku przez Piotra Jakóbczyka. Obecnie prowadzona przez Marcina Gołębiowskiego. Aktywnie promująca technologie Microsoft na Wydziale Matematyki i Informatyki Uniwersytetu Wrocławskiego poprzez spotkania oraz pomoc studentom w ich pierwszych krokach w technologii .NET.

#### Polska Grupa Użytkowników SQL Server we Wrocławiu
Polish SQL Server User Group (PLSSUG) jest grupą pasjonatów systemu Microsoft SQL Server. Naszym celem jest umożliwienie jak najszerszemu gronu ludzi poznawania naszego ulubionego systemu zarządzania bazami danych oraz dzielenia się z innymi swoją wiedzą i doświadczeniem.

#### Stowarzyszenie AVEC
Stowarzyszenie AVEC zostało założone przez studentów Uniwersytetu Wrocławskiego. Głównym celami AVEC są: promowanie idei całożyciowego uczenia się, organizacja konferencji oraz pomoc innym organizacjom w realizowaniu imprez naukowych.

#### Stowarzyszenie Coworking Kraków
Stowarzyszenie Coworking Kraków zostało powołane w celu popularyzacji idei coworkingu, jako nowego podejścia do wykonywania pracy, w którym główny nacisk stawia się na tworzenie społeczności mikroprzedsiębiorstw (jedno i kilkuosobowych) wokół wspólnego miejsca pracy.
