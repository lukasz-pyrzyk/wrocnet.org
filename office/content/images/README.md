# Wroc.NET images

Folder `images/` zawiera wszystkie grafiki związane z treścią: referencje marki oraz gotowe grafiki kampanii.

## Konwencja nazewnictwa

- `brand-*` — referencyjne grafiki marki dla agenta AI (styl, kolorystyka, kompozycja), np. `brand-meetup-announcement-01.jpg`
- `YYYY-MM-DD-opis.jpg/png/jpeg` — gotowe grafiki konkretnej kampanii/posta, np. `2026-09-05-call-for-speakers-hero.jpeg`

## Baner grupy Meetup

[2026-10-20-meetup-organizatorzy.jpg](2026-10-20-meetup-organizatorzy.jpg) - JPG, 1200 × 675 px (16:9), do ręcznego wgrania jako główne zdjęcie grupy. Przy zmianie składu wymaga aktualizacji; nie synchronizuje się automatycznie z Meetup.

Przed proponowaniem nowej grafiki AI sprawdź pliki `brand-*` — traktuj je jako źródło prawdy dla stylu, kompozycji i kolorystyki.

Najlepiej przechowywać 5–10 reprezentatywnych przykładów `brand-*` zamiast dużej liczby podobnych plików.
