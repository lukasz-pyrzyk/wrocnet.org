# Wroc.NET Content Samples

Rzeczywiste przykłady treści Wroc.NET, podzielone tematycznie. Użyj ich jako punktu wyjścia zamiast pisać od zera.

- **emails/** — maile do społeczności, prelegentów, partnerów
- **announcements/** — ogłoszenia i szablony (preferuj multi-channel: LinkedIn, Twitter/X, Newsletter + prompty do grafik w jednym pliku na temat)
- **briefs/** — hasła, tagi, opisy do grafik

## Jak używać

1. Znajdź plik pasujący do kontekstu (np. call for speakers → `announcements/call-for-speakers-template.md`)
2. Adaptuj strukturę i ton, personalizuj dane
3. Po wysłaniu/opublikowaniu, zarchiwizuj finał zgodnie z workflow opisanym w [office/content/README.md](../README.md)

Pełne konwencje nazewnictwa, metadane i workflow Git są w [office/content/README.md](../README.md) — nie duplikuj ich tutaj.
