# Wroc.NET brand references

Folder `examples/` zawiera przykładowe grafiki i materiały referencyjne dla agenta AI.

Dodawaj tutaj:
- grafiki meetupów;
- banery;
- posty graficzne;
- przykłady typografii i layoutów;
- materiały pokazujące właściwą kolorystykę.

Nazwy plików powinny być opisowe, np.:
- `meetup-announcement-01.png`
- `partner-announcement-01.png`
- `speaker-card-01.png`
- `social-banner-01.png`

Najlepiej przechowywać 5–10 reprezentatywnych przykładów zamiast dużej liczby podobnych plików.
